GDNA v17 Decode/Reconstruction UI patch validation
===================================================

Changes
-------
1. Image Decode/Reconstruction display now uses one 3-column horizontal row:
   - Encoded Reference
   - Reconstructed image / Noisy reconstructed image
   - Binary error mask
2. Decode upload modes now include:
   - Source bits
   - Source DNA
   - Full bitstream
   - Full DNA
3. Source-only Decode uses the current encoded Critical Header and Extended Metadata,
   while the uploaded source artifact supplies the potentially modified canonical source.
4. Source-only upload is substitution-only: source length must remain unchanged.
5. Existing Stress Test and media support (image/text/audio) are retained.
